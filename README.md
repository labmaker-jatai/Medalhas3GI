# 🏅 Medalhas da III Gincana Integradora do IFG – Câmpus Jataí

Projeto de **desenvolvimento e fabricação das medalhas da III Gincana Integradora do IFG – Câmpus Jataí**, produzidas em **MDF utilizando tecnologia de corte a laser**.

Além da confecção das medalhas, o projeto foi desenvolvido com foco no **aproveitamento eficiente da matéria-prima**. Os recortes internos gerados durante o corte das medalhas foram reutilizados na produção de **chaveiros**, transformando partes que seriam normalmente descartadas em novos produtos.

Essa abordagem permitiu reduzir o desperdício de MDF e otimizar o aproveitamento das chapas utilizadas na fabricação.

## ✨ Características

- 🏅 Medalhas personalizadas para a **III Gincana Integradora do IFG – Câmpus Jataí**;
- 🔑 Chaveiros produzidos a partir dos recortes internos das medalhas;
- ♻️ Reaproveitamento de material e redução de desperdícios;
- 🔥 Fabricação por **corte a laser**;
- 📐 Projeto desenvolvido visando o melhor aproveitamento das chapas de MDF;
- 💻 Arquivos disponibilizados em diferentes formatos para facilitar a edição e a fabricação.

## 📁 Arquivos

O repositório contém os modelos utilizados no projeto nos seguintes formatos:

- **`.DXF`** — formato vetorial amplamente utilizado em softwares CAD;
- **`.SVG`** — formato vetorial para edição e utilização em diferentes softwares de fabricação;
- **`.WCVR`** — formato utilizado pelo software **AutoLaser**, empregado na operação das máquinas de corte a laser equipadas com controladoras **TopWisdom**.

Os arquivos `.WCVR` correspondem aos arquivos preparados especificamente para utilização no fluxo de fabricação das máquinas de corte a laser.

## 🛠️ Fabricação

O processo combina **modelagem vetorial, otimização do aproveitamento da chapa e fabricação digital por corte a laser**.

Um dos objetivos do projeto foi aproveitar não apenas a área principal da chapa, mas também os materiais resultantes dos recortes internos das medalhas. Dessa forma, os próprios recortes foram incorporados ao projeto dos chaveiros, contribuindo para uma fabricação mais eficiente e com menor geração de resíduos.
