# Medalhas da III Gincana Integradora do IFG – Câmpus Jataí

Projeto de fabricação das medalhas da **III Gincana Integradora do IFG – Câmpus Jataí**, desenvolvidas em **MDF por meio de corte a laser**.

O projeto foi pensado para otimizar o uso do material: os recortes internos das medalhas foram aproveitados na produção de **chaveiros**, reduzindo o desperdício de MDF e dando uma nova utilidade às partes que normalmente seriam descartadas.

### Características

- 🏅 Medalhas personalizadas para a III Gincana Integradora;
- 🔑 Chaveiros produzidos a partir dos recortes internos das medalhas;
- 🌱 Aproveitamento e redução do desperdício de material;
- 🔥 Fabricação utilizando tecnologia de corte a laser;
- 📐 Projeto desenvolvido para otimizar o aproveitamento das chapas de MDF.
